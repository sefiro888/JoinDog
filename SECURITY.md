# Security Policy — DOGCRUSH

## Security Practices
- No API keys, passwords, authentication tokens, `.env` files, or keystore private keys are tracked in this repository.
- Version 0.1 is an offline, standalone prototype that makes no external network requests and connects to no third-party servers.

## Reporting a Vulnerability
If you discover any security issue or secret leak in this repository, please notify the repository owner directly. Do not publicly disclose vulnerabilities until they have been addressed.
